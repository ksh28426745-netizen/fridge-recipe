# 냉장고 요리 추천

냉장고에 있는 재료를 고르면 만들 수 있는 한국 가정식 요리를 추천해 주는 웹앱입니다.

- 재료 84가지, 요리 50가지
- 재료를 고르면 지금 바로 만들 수 있는 요리부터 보여 줍니다
- 각 요리마다 재료·분량·조리 순서와 유튜브 레시피 검색 링크 제공
- 휴대폰·태블릿·노트북 화면 크기에 맞춰 보입니다 (설치 없이 브라우저에서 바로 실행)
